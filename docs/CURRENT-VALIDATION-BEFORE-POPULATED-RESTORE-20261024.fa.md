# وضعیت جاری نسخهٔ ۲٫۱٫۲ — ۲۴ اکتبر ۲۰۲۶

**بکاپ مستقل، دانلود و احراز اصالت، restore واقعی همان میزبان و readback مستقلِ داده‌های اولیه موفق‌اند؛ مجموعهٔ عملیات ۲۰۶/۲۰۶ است.** اجرای دوم API و اسکن واقعی فایل پاک/EICAR نیز ۱۲/۱۲ موفق شد؛ شکست نخست ابزار انتقال محفوظ است. نصاب کاملِ تلاش ۶ همچنان ناموفق با خروج ۱۲۴ است؛ build05 بومی، بازیابی میزبان تازه و ماتریس کامل Lighthouse در انتظارند. [گزارش پذیرش](VERIFICATION.fa.md) و [خلاصهٔ ماشینی](verification-evidence/repair-2.1.2/acceptance.json) مرجع دامنهٔ هر نتیجه‌اند.

نتایج پیشین ۸۱۵/۸۱۵ واحد، ۵۴۲/۵۴۲ PostgreSQL، ۲۰/۲۰ API، ۵۶/۵۶ مرورگر build02 و بررسی‌های مرتبط build03/04 با دامنهٔ اصلی حفظ شده‌اند؛ آزمون تازه معرفی نمی‌شوند. JavaScript/TypeScript، دیتابیس، CSS، دارایی و lockfile در این دو اصلاح عملیات تغییر نکرده‌اند.
