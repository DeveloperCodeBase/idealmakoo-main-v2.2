# اصلاح تعامل کروسل، منوهای موبایل و جهت زبان‌ها

این انتشار روی همان پروژهٔ Next.js و TypeScript اعمال شده است. طراحی شیشه‌ای و نئون، داده‌های کارخانه، پنج زبان و مجوزهای نقش‌ها از ساختار مشترک موجود استفاده می‌کنند.

## تغییر رفتار رابط

### کروسل‌های مشترک

- کشیدن افقی با موس، قلم و لمس، کارت‌ها را جابه‌جا می‌کند. تشخیص جهت حرکت، اسکرول عمودی و زوم لمسی مرورگر را حفظ می‌کند.
- حرکت کارت‌ها حین درگ نمایش داده می‌شود و پس از رهاکردن، انتخاب نهایی تثبیت می‌شود. سوایپ سریع نیز در لحظهٔ رهاکردن بررسی می‌شود.
- رهاکردن بیرون کروسل، لغو لمس، چندلمسی و خروج فوکوس مرورگر، حالت درگ را پاک می‌کند.
- پایان درگ پنجرهٔ جزئیات را تصادفی باز نمی‌کند؛ لمس یا کلیک عمدی بعدی همچنان فعال است. دکمه‌ها و میانبرهای قبلی نیز کار می‌کنند.

### سایدبار، نوبار و حساب‌ها

- سایدبار میزکار در عرض ۹۸۰ پیکسل و کمتر به شکل پنجرهٔ بومی `dialog` در لایهٔ بالایی باز می‌شود. پس‌زمینه محو می‌شود و خود سایدبار در لایهٔ واضح باقی می‌ماند.
- منوی حساب شخصی نیز سایدبار موبایل دارد: هویت و عکس کاربر، پروفایل، تنظیمات، سازمان‌ها، درخواست‌ها، ماتریس سفارش، ذخیره‌شده‌ها، اعلان‌ها و امنیت. پیوند میزکار برای نقش‌های مجاز کارکنان نمایش داده می‌شود.
- محتوای منوی میزکار در دسکتاپ و موبایل از همان فیلتر مجوز نقش ساخته می‌شود؛ اندازهٔ نمایش مجوز تازه ایجاد نمی‌کند.
- بستن با دکمه، لمس فضای بیرون، Escape، انتخاب پیوند، تغییر زبان و بازگشت به عرض دسکتاپ مدیریت می‌شود. فوکوس و قفل اسکرول با چرخهٔ پنجره هماهنگ‌اند.
- فضای امن نمایشگر، ارتفاع قابل مشاهده، اسکرول داخلی منو و کنترل‌های لمسی رعایت شده‌اند. نوبار در عرض‌های کم و اندازهٔ متن بزرگ، چیدمان مناسب خودش را دارد.

### چیدمان صفحات و اسکرول

- ردیف‌های محصول، استعلام و مقایسه، فرم‌ها، مسیر راهنما، برچسب‌های بلند، تنظیمات و محتوای حساب در عرض کم جمع می‌شوند یا خط بعد می‌روند. جدول‌ها، کانبان و نمایشگر اسناد، ناحیهٔ اسکرول خودشان را حفظ می‌کنند.
- قفل اسکرول پنجره دیگر مختصات صفحهٔ قبلی را پس از تغییر نشانی روی صفحهٔ جدید اعمال نمی‌کند. ورود معمول به مسیر جدید و انتخاب دوبارهٔ خانه پس از بسته‌شدن منو به بالای صفحه می‌روند.
- پیوندهای دارای لنگر و مسیرهای Back/Forward از بازنشانی اجباری اسکرول مستثنا هستند. تعامل تازهٔ کاربر، فریم‌های معلق بازنشانی را لغو می‌کند.
- اسکرول پاسخ‌های دستیار فقط داخل فهرست پیام‌ها انجام می‌شود؛ بازگرداندن فوکوس به ورودی، درخواست جابه‌جایی صفحه نمی‌کند.
- پایین سایت، نام «شرکت شبکه هوشمند ابتکار ویستا» با عنوان تهیه و پیاده‌سازی نمایش داده می‌شود. عنوان در پنج زبان موجود ترجمه شده است.

## اجرا و بررسی

پیش‌نیاز Node.js 24 یا جدیدتر است. پس از استخراج ZIP در پوشهٔ `idealmakoo`:

```bash
npm ci
cp .env.example .env.local
npm test
npm run build
npm run check
PORT=3100 npm start
```

آدرس نمونهٔ اجرا `http://127.0.0.1:3100/fa/` است. پورت ۳۱۰۰ صرفاً نمونه است؛ روی سرور دارای چند پروژه باید پورتی که واقعاً آزاد است و تنظیم سرویس همان پروژه را انتخاب کنید. دستور `npm start` سرور همراه پروژه را اجرا می‌کند؛ خروجی پروژه استاتیک است و با `next start` اجرا نمی‌شود. تنظیمات سروری در `.env.local` قرار می‌گیرند و ZIP سورس، کلیدها یا وابستگی‌های نصب‌شده را شامل نمی‌شود.

آزمون‌های افزوده، رویدادهای موس/لمس، آزادشدن اشاره‌گر، جلوگیری از کلیک پس از درگ، حرکت RTL/LTR و چرخهٔ قفل و بازنشانی اسکرول را در محیط آزمون کنترل می‌کنند. آزمون‌های نقش و مالکیت موجود نیز جزو `npm test` هستند. `npm run check` نوع‌های TypeScript، مسیرها، منابع خروجی و هماهنگی بستهٔ دانلود با سورس را بررسی می‌کند.

**مرز اعتبارسنجی:** این محیط مرورگر تعاملی پشتیبانی‌شده یا دستگاه واقعی در اختیار ندارد. آزمون‌ها، ساخت موفق و بررسی CSS جای بررسی دیداری و لمس روی گوشی واقعی را نمی‌گیرند. سناریوهای زیر برای بررسی دستگاه واقعی باقی می‌مانند:

1. در محصولات، کاتالوگ و خبرها با موس یا لمس افقی کارت را بکشید؛ با حرکت عمودی صفحه را اسکرول کنید؛ سپس یک کارت را عمداً باز کنید.
2. در فارسی و عربی، منوی عمومی، حساب و میزکار را از راست باز کنید؛ در انگلیسی، ترکی و روسی همین منوها باید از چپ باز شوند.
3. با حساب کاربر حرفه‌ای و هر نقش کارکنان، منوی موبایل را باز کنید و پروفایل و تنظیمات و بخش‌های مجاز همان نقش را بررسی کنید. حساب‌های آزمایشی در README هستند.
4. در پایین یک صفحه، منو را باز و خانه را انتخاب کنید. همین کار را در پایین خود خانه تکرار کنید. Back، Forward و پیوندهای لنگردار را نیز بررسی کنید.
5. حالت روشن و تیره، متن بزرگ، عرض‌های باریک، چرخاندن گوشی و بازبودن صفحه‌کلید را بررسی کنید. پس از بستن منو، اسکرول و فوکوس باید آزاد باشند.

## انتشار

این سورس روی پروژهٔ موجود Sites قابل انتشار است. انتقال آن به VPS یا دامنهٔ مستقل، مرحلهٔ جداگانهٔ همان سرور است؛ موفقیت ساخت یا انتشار Sites به معنی تغییر VPS نیست. نسخهٔ کامل دانلود هنگام `npm run build` بازسازی می‌شود و `SOURCE-MANIFEST.json` درون آن، هش فایل‌ها را برای تطبیق ثبت می‌کند.
