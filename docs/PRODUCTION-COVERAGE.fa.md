# تطبیق درخواست‌ها با تحویل ۲٫۲٫۰

این جدول وضعیت قابلیت و مسیر استفاده را توضیح می‌دهد. نتیجهٔ اجرای آزمون، تعداد موفق/ناموفق و محدودیت محیط در [گزارش پذیرش](VERIFICATION-2.2.0.fa.md) ثبت شده است. سابقهٔ نسخهٔ قبلی جدا حفظ شده است.

| درخواست | پیاده‌سازی و محل استفاده | شرط و حد واقعی |
| --- | --- | --- |
| سند حرفه‌ای و برنامه پیش از اجرا | سند تفصیلی توسعه و برنامهٔ اجرای ۲٫۲ | پس از بررسی ZIP مبنا و پیش از تغییر قابلیت‌ها نوشته شدند؛ تفاوت‌های نهایی در سند اصلاح شده‌اند. |
| نصب با توقف روی خطا و راهکار محدودیت شبکه | preflight، تشخیص شبکه، retry محدود دریافت، proxy اختیاری، image محلی، doctor | خطای دائمی دور زده نمی‌شود؛ اینترنت ایران یا دسترسی provider تضمین نشده است. |
| ایمیل‌سرور روی دامنهٔ سایت | `--with-mail-server`، SMTP/IMAP، TLS، DKIM و بکاپ format4 | DNS/PTR، IP و پورت‌ها باید در محیط مالک آماده شوند؛ SMTP خارجی قابل حفظ است. |
| ورود و ثبت‌نام پیامکی | `/auth/otp/status`، request و verify و فرم پنج‌زبانه | provider فعلی کاوه‌نگار است؛ قالب و اعتبار واقعی لازم است؛ کارکنان از این مسیر وارد نمی‌شوند. |
| اعلان انتشار با متن، تصویر و لینک | قالب اختصاصی ایمیل/تلگرام/SMS، رضایت موضوع و زبان، صف پایدار | فقط محتوای منتشرشده؛ SMS تصویر ندارد؛ تصویر باید عمومی و مجاز باشد. |
| پیام مشتری و استعلام به نقش مرتبط | اعلان داخلی و کانال تأییدشدهٔ کارکنان با کنترل مجوز هنگام صف و ارسال | محدودهٔ پرونده، زبان و نقش اعمال می‌شود؛ هشدار عمومی شامل متن خصوصی کامل نیست. |
| تماس مشتری | فرم درخواست تماس، فعالیت CRM و ورودی connector امضاشده | تشخیص تماس تلفنی بیرون سایت نیازمند اتصال PBX یا ثبت دستی است. |
| نظر، لایک، گزارش و اختیار انتشار | تعامل عمومی و صف ناشر/مدیر، فیلتر وضعیت و تصمیم ثبت‌شده | نظر تخت است؛ پیش از تأیید عمومی نیست؛ آخرین ۵۰ نظر تأییدشده بازگردانده می‌شود. |
| آمار روی محتوا و در پنل | آمار عمومی حداقلی، تحلیل مجاز با بازه و زبان و روند روزانه | بازدید بر مبنای مرورگر/محتوا و پنجرهٔ ۳۰ دقیقه است؛ تعداد قطعی اشخاص یا ثبت همهٔ کلیک‌ها نیست. |
| گزارش هر اتفاق مدیریتی | audit و monitoring موجود، رخدادهای احراز هویت/انتشار/درخواست/تصمیم، گزارش تعامل تازه | رویدادهای ثبت‌شدهٔ سرور قابل بررسی‌اند؛ سامانه ابزار عمومی ضبط جلسهٔ مرورگر نیست. |
| استعلام حرفه‌ای | پرونده و شمارهٔ پیگیری، تخصیص، یادداشت عمومی/داخلی، گردش پیشنهاد قیمت موجود، هشدار تازه | مشتری دارای موبایل تأییدشده نیاز به ایمیل ندارد؛ دسترسی تماس/مالی مستقل است. |
| AI اختیاری برای نقش‌ها | دستیار ۱۱ نقش کارکنان با موضوع و زبان مجاز، انتخاب پروندهٔ مجاز، کمک محتوا/SEO/محصول/تحلیل | نیاز به provider، مدل و بودجه دارد؛ هر درخواست صریح است؛ خروجی خودکار منتشر نمی‌شود. |
| گزارش مصرف و هزینهٔ API | مصرف تأییدشدهٔ کانال‌ها، گزارش AI، هزینهٔ واقعی/تخمینی/نامعلوم و وضعیت صف | AI و SMS ارز متفاوت دارند؛ نرخ نامعلوم صفر نیست؛ بودجهٔ روزانهٔ SMS اضافه نشده است. |
| دسته‌بندی دقیق | خانوادهٔ محصول، نوع منبع و دسته/برچسب در snapshot منتشرشدهٔ محتوا و صفحه | دسته‌ها قابل تنظیم‌اند؛ یکسان‌سازی واژگان و نگهداری طبقه‌بندی با مسئول محتواست. |
| جست‌وجوی جامع و بلادرنگ | فیلتر نوع/دسته، صفحه‌بندی، همسان‌سازی فارسی/عربی/عدد، رتبه‌بندی متن و خطای تایپی محدود، پاسخ تازه | فقط دادهٔ عمومی منتشرشده؛ جست‌وجوی عمومی به CRM و پیش‌نویس متصل نیست؛ جست‌وجوی معنایی AI ادعا نشده است. |
| سایت‌مپ و ایندکس | index زبان/نوع، قطعه‌های محدود، canonical و hreflang و lastmod واقعی، robots | Google/Bing/Yandex راهنما دارند؛ IndexNow داخلی و ایندکس تضمینی ارائه نشده‌اند. |
| آموزش جامع هر نقش با عکس | ۱۲ Markdown مستقل، ۱۳ صفحهٔ HTML شامل فهرست، تصاویر واقعی آموزشی، کتابچهٔ Word | برچسب‌ها/مسیرها با UI جاری تطبیق داده شده‌اند؛ داده و آمار تصاویر آموزشی است. |
| انعطاف‌پذیری | پنج زبان، نقش/زبان/محدوده و مجوز مستقل، ترجیحات کانال، provider و مدل AI، SMTP محلی/خارجی، taxonomy | افزودن provider پیامک یا اتصال PBX جدید به adapter و آزمون همان سرویس نیاز دارد. |
