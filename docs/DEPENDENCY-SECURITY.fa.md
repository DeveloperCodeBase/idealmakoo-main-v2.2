# امنیت وابستگی‌ها — نسخهٔ ۲٫۱٫۴

تاریخ اجرای تازه: **۲۰۲۶-۱۰-۲۵**. این گزارش به `package-lock.json` نسخهٔ ۲.۱.۴ تعلق دارد. گزارش قبلی بدون تغییر در [سابقهٔ ۲.۱.۳](DEPENDENCY-SECURITY-2.1.3-HISTORICAL.fa.md) نگه‌داری شده است.

## نتیجهٔ واقعی اسکن

| بررسی | پیش از اصلاح این نسخه | پس از اصلاح |
| --- | --- | --- |
| تمام وابستگی‌ها، شامل ابزار ساخت | ۳ مدخل متوسط؛ صفر high و critical | صفر مدخل در تمام شدت‌ها |
| ریشهٔ گزارش | `postcss-selector-parser` و وابسته‌های `postcss-nested` و `tailwindcss` | نسخهٔ قفل‌شدهٔ parser برابر `7.1.6` |
| نصب وابستگی‌ها | نصب واقعی با `npm ci` از lockfile | موفق؛ نتیجه از درخت نصب قدیمی فرض نشده است |

سه مدخل اولیه سه نقص مستقل در مسیر پاسخ‌گویی سایت نبودند؛ npm زنجیرهٔ وابسته‌ها را نیز گزارش می‌کرد. خروجی اولیه حذف نشده است. [گزارش اولیه](verification-evidence/repair-2.1.4/npm-audit-before.json) و [گزارش نهایی](verification-evidence/repair-2.1.4/npm-audit-after.json) برای بررسی همراه بسته‌اند.

صفر بودن یافته‌های این اسکن، فقط نتیجهٔ پایگاه advisory و lockfile در زمان اجراست؛ گواهی نبود تمام نقص‌های احتمالی برنامه یا سرویس‌های میزبان نیست. آزمون‌های نشست، نقش، دیتابیس و مرورگر شواهد جداگانه دارند.

## تغییر محدود و کنترل حفظ طراحی

در `package.json` مقدار دقیق `postcss-selector-parser: 7.1.6` در `overrides` ثبت و lockfile بازتولید شد. Tailwind روی `3.4.17` باقی مانده است؛ مهاجرت عمدهٔ سیستم استایل انجام نشده است. نسخهٔ قبلی `6.1.5` در سابقهٔ نگهدارنده به‌عنوان backport معرفی شده بود، اما گزارش تجمیعی جاری بازهٔ `<7.1.6` را برمی‌گرداند. تصمیم این انتشار، استفاده از نسخهٔ اصلاح‌شدهٔ جاری با بررسی سازگاری واقعی بود.

برای این بررسی، دو نسخهٔ parser در resolverهای جدا روی یک مجموعهٔ ثابت از ورودی‌ها اجرا شدند. خروجی پردازش **۳۸ فایل CSS** با مجموع **۵۲۸٬۷۶۵ بایت** و فهرست warningها بایت‌به‌بایت یکسان بود. آزمون مستقل Tailwind روی ۵۴۸ ورودی ثابت نیز خروجی ۱۵٬۴۰۹ بایتی یکسان تولید کرد. این بررسی اثر تغییر dependency بر همان ورودی ثابت را می‌سنجد؛ تغییر عمدی راهنمای پنل یا کد بعدی لزوماً hash خروجی نهایی را ثابت نگه نمی‌دارد.

[تطبیق CSS](verification-evidence/repair-2.1.4/dependency-css-equivalence.safe.json)، ساخت production و آزمون مرورگر، شواهد سازگاری این تصمیم هستند. Next `16.4.2` و `sharp 0.35.5` در بستهٔ مبنا نیز وجود داشتند و در این اصلاح ارتقا داده نشده‌اند.

## تکرار بررسی و نگهداری

از ریشهٔ سورس و در محیط دارای دسترسی شبکه:

```bash
npm ci --no-audit --no-fund
npm audit --json
npm audit --omit=dev --audit-level=high
npm run typecheck
npm test
npm run build
```

فرمان‌ها را با زمان، کد خروج و خروجی خام همان اجرا ثبت کنید. `npm audit fix --force` را به‌عنوان جایگزین بررسی سازگاری و کنترل طراحی به کار نبرید. اگر اسکن بعدی یافتهٔ تازه‌ای برگرداند، نتیجهٔ این گزارش را برای آن زمان تعمیم ندهید؛ اطلاعیهٔ اصلی، نسخهٔ نصب‌شده، مسیر استفاده و اصلاح معتبر را بررسی کنید.
