# وضعیت جاری نسخهٔ ۲٫۱٫۳

مرجع نتیجهٔ جاری، [گزارش پذیرش ۲.۱.۳](VERIFICATION.fa.md) است. این نسخه اصلاح انقضای اثبات ورود پس از قفل دیتابیس را دارد؛ حفظ قالب اصلی، مبنای اصلاحات رابط است.

در بستهٔ اول، ۸۱۵ آزمون واحد، ۵۴۸ آزمون PostgreSQL، ۲۰ آزمون API، TypeScript، ساخت production، ۵۶ آزمون مرورگر و بررسی metadata تعداد ۶۲۰ URL موفق‌اند. نصب تازهٔ Ubuntu، ۱۲ کنترل API عملیاتی، بکاپ داده‌دار و دانلود/اعتبارسنجی مستقل، و پنج کنترل تغییر/حذف پس از بکاپ نیز موفق‌اند. بازیابی روی Ubuntu مستقل، تطبیق سورس و دیتابیس، شاهد نشست/MFA/دفتر حذف پیش از ورود و ۱۹ کنترل API پس از آن هم با خروج صفر تمام شده‌اند. [شواهد عملیاتی](OPERATIONS-ACCEPTANCE-2.1.3.fa.md) به hash همان بسته تعلق دارند.

مقایسهٔ ۴۸ اجرای CSS تمام شده و ارسال فایل‌های جداگانه انتخاب شده است؛ میانهٔ Performance نمونه‌های عمومی ۳ تا ۷ امتیاز بهتر شد و موازنهٔ زمان نمایش اولیه نیز ثبت شده است. گالری، مکث پیش‌نمایش هنگام تایپ و favicon کوچک‌تر در سورس یکپارچه‌اند. روی ساخت C2 با شناسهٔ `JUTCtkNIJ8CT540y_qNL_`، هر ۸۲۰ آزمون واحد، TypeScript، هر ۵۶ آزمون مرورگر، هفت کنترل متمرکز گالری و بررسی metadata هر ۶۲۰ URL با دریافت پایان واقعی موفق‌اند.

**سورس جاری C3**، ساخت `DuF4NV2a3keq3h3H5T3Dr`، [پرش بارگذاری منابع](RESOURCES-LOADING-2.1.3.fa.md) را نیز اصلاح می‌کند. هر ۸۲۰ آزمون واحد، TypeScript و ساخت دوباره موفق‌اند. در ۱۰ بررسی واقعیِ پنج زبان و دو viewport، جابه‌جایی انتظار تا آماده صفر پیکسل و DOM نهایی با C2 یکسان بود. یک Lighthouse تشخیصی منابع عربی Performance ۵۴، سه امتیاز دیگر ۱۰۰ و CLS صفر ثبت کرد. این یک نمونه است. بررسی metadata هر ۶۲۰ مسیر و هر ۲۵ موجودی تازه نیز موفق‌اند؛ موجودی C3 در آن مرحله ۱۲۲۳ حالتِ بدون امتیاز نهایی دارد.

تفاوت C3 با C2 دقیقاً دو فایل نمایشی و سازگاری یک آزمون موجود است؛ ۹۹۱ ورودی اجرایی دیگر برابرند. آزمون‌های کامل مرورگر/بک‌اند و Ubuntu در این مرحله تکرار نشده‌اند و نتیجهٔ قبلی به‌عنوان اجرای تازهٔ C3 گزارش نمی‌شود.

ارتقای همان نصب بازیابی‌شده به سورس نهایی C2 موفق است: فرمان اصلی یک بار با خروج صفر اجرا شد؛ تطبیق ۳۵۳۵ فایل release، ۶۶۸ فایل سورس image، هر ۴۱ migration، نقش محدود دیتابیس، داده‌ها، env و دفتر حذف موفق‌اند. هر دو بکاپ اجباری ساخته شدند، ۱۹ کنترل API پس از ارتقا گذشتند و ماشین به‌صورت عادی با دریافت پایان واقعی خاموش شد. حدود این نتیجه، از جمله تفاوت اعتبارسنجی دو بکاپ ارتقا با رمزگشایی و بازیابی مستقل آرشیو قبلی، در [گزارش عملیاتی](OPERATIONS-ACCEPTANCE-2.1.3.fa.md) آمده است.

ممیزی امتیازدار نهایی C3، شامل ۱۱۵۰ حالت کامل موبایل و ۷۳ حالت منتخب دسکتاپ، هنوز نتیجهٔ بسته‌شده ندارد. دو batch بسته‌شدهٔ C2 شامل ۱۹۸ گزارش Lighthouse و دو 404 مورد انتظار با صفر خطا/timeout، سابقهٔ جداگانه‌اند. گزارش اصلی با رسید واقعی هر مرحله به‌روز می‌شود؛ این صفحه موفقیت مرحلهٔ اجرا‌نشده یا پوشش کامل دسکتاپ را اعلام نمی‌کند.

[سوابق ۲.۱.۲](CURRENT-VALIDATION-2.1.2-HISTORICAL.fa.md) متعلق به اجرای قبلی‌اند. برای نصب تازه یا ارتقا از [START-HERE](START-HERE.fa.md) آغاز کنید.
