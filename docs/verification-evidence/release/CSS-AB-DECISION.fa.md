# تصمیم دربارهٔ آزمایش CSS خارجی

**حذف سراسری `experimental.inlineCss` برای نسخهٔ تحویلی پذیرفته نشد.** این آزمایش حجم سند HTML را کم کرد، اما در مجموعهٔ ثابت اندازه‌گیری، بهبود قابل اتکایی در عملکرد نشان نداد. تصمیم، حفظ تنظیم قبلی است؛ این یادداشت به‌تنهایی گواه اجرای بازگردانی یا پذیرش یک بیلد بعدی نیست.

۲۵ نمای اول موجودی پنل، همگی با نقش `superAdmin` و زبان عربی، و سه مسیر عمومی فارسی خانه، تماس و تولید مقایسه شدند. برای هر مسیر دقیقاً اولین تلاش قبل و بعد در مقایسه آمده است. مسیرهای عمومی از همان وضعیت دادهٔ آزمون پذیرش استفاده کردند؛ این سنجش، پیمایش کامل ۶۲۰ مسیر عمومی یا ۵۳۰ نمای خصوصی نیست. نمره‌های پایین حذف یا با تلاش بهتر جایگزین نشده‌اند.

«میانهٔ تغییر جفت‌شده» از اختلاف هر مسیر با همان مسیر محاسبه می‌شود و الزاماً برابر اختلاف دو میانهٔ گروه نیست. اعداد دقیق هر ۲۸ جفت، هر ۵۶ تلاش، تمام شاخص‌ها و بازه‌ها در [گزارش مقایسه](css-external-styles-comparison.json) حفظ شده‌اند؛ نمایش گرد شدهٔ جدول جایگزین دادهٔ کامل نیست.

در پنل، میانهٔ حجم انتقال خود HTML از ۱۴۴٬۹۹۷ به ۱۱٬۰۵۲ بایت رسید؛ میانهٔ CSS خارجی از ۶٬۲۱۵ به ۸۱٬۴۹۰ بایت افزایش یافت. CSS و JavaScript داخلی همچنان بخشی از بایت‌های Document هستند و نباید دوباره به مجموع اضافه شوند. این کاهش HTML به‌تنهایی اثبات سریع‌ترشدن صفحه نیست؛ در تمام ۲۵ جفت پنل FCP بیشتر شد و در دو مسیر عمومی LCP افزایش یافت. میانهٔ Performance پنل از ۶۵ به ۶۲ و عمومی از ۸۲ به ۷۶ رسید. Accessibility و Best Practices همهٔ جفت‌ها ۱۰۰ بودند؛ این نمره به‌معنای انطباق کامل دسترس‌پذیری نیست و SEO پایین‌تر صفحات خصوصیِ `noindex` نباید با ضعف سئوی صفحات عمومی اشتباه گرفته شود.

این اندازه‌گیری فقط یک اجرای قبل و یک اجرای بعد برای هر مسیر است. هویت دادهٔ خصوصی آزمون بین دو گروه برابر نبود: از چهار جزء ثبت‌شده، چکیده‌های `workspace_entities`، `workspace_meta` و `requests` متفاوت و چکیدهٔ `locale_releases` یکسان بودند. وضعیت هر گروه، بین ثبت آغاز و پایان همان اجرا، ثابت بود. این شواهد فقط چکیدهٔ داده‌ها را نگه می‌دارند و رکوردها، فیلدهای تغییرکرده یا علت تفاوت را مشخص نمی‌کنند. هویت محتوای عمومی برابر بود. تنظیمات اعلام‌شده و مشخصات میزبان یکسان بودند، ولی یکسان‌بودن رقابت لحظه‌ای CPU، حافظه یا وضعیت cache اثبات نشده است. بنابراین نسبت‌دادن قطعی همهٔ اختلاف‌ها به CSS، ادعای معناداری آماری، نتیجهٔ INP کاربران واقعی یا تضمین بهبود همهٔ صفحات مجاز نیست.

دو خطا و یک timeout در پیمایش خصوصی اولیه، با همان طبقه‌بندی اصلی و تعداد ۴۱۴ نمای باقی‌مانده، در گزارش حفظ شده‌اند؛ آن‌ها خارج از ۲۵ مسیر ازپیش‌تعیین‌شدهٔ این مقایسه بودند. فرمان نخستِ آماده‌سازی نمونهٔ عمومی نیز به‌علت نبودن loader `--import tsx` پیش از ساخت موجودی شکست خورد؛ Chrome و گزارش امتیاز ایجاد نشد. آن تلاش محفوظ است و اجرای اصلاح‌شده سه سنجش واقعی مبنا را ایجاد کرد.

تغییر جداگانهٔ پیشنهادی برای انتقال وابستگی صفحهٔ ورود به مسیر اختصاصی آن، یا بهینه‌کردن thumbnailهای عمومی شناخته‌شده، جزو این آزمایش نیست و این گزارش هیچ بهبودی برای آن‌ها ادعا نمی‌کند. پذیرش نهایی محصول و پیمایش کامل صفحات همچنان جداگانه باقی می‌مانند.
