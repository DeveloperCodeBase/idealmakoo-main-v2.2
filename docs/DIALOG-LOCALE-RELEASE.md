# اصلاح دیالوگ‌های شیشه‌ای و ثبات زبان

این انتشار، مشکلات گزارش‌شده در قاب دیالوگ حساب شخصی، ظاهر ناهماهنگ پنجره‌ها و تغییر ناخواستهٔ زبان هنگام جابه‌جایی را در همان پروژهٔ Next.js و TypeScript اصلاح می‌کند.

## قاب، سربرگ و بدنهٔ پنجره‌ها

در تصویر گزارش‌شده، سربرگ با حاشیهٔ منفی از محدودهٔ بدنه بیرون می‌آمد، اما محدودیت عرض عمومی آن را می‌برید. قاب تزئینی عمومی شیشه و فضای نوار اسکرول نیز لبهٔ دوم جابه‌جاشده ایجاد می‌کردند.

پوستهٔ مشترک پنجره یک قاب واحد دارد: سربرگ در جای خود باقی می‌ماند و بدنهٔ بلند، اسکرول داخلی دارد. سطح پنجره، نور و انعکاس، لبه و سایه از تعریف مشترک Liquid Glass استفاده می‌کنند. این ساختار برای فارسی/عربی راست‌به‌چپ و انگلیسی/ترکی/روسی چپ‌به‌راست و هر دو تم تنظیم شده است. بازتاب موس ظاهر سطح را تغییر می‌دهد؛ موقعیت دکمه‌ها هنگام تعامل جابه‌جا نمی‌شود.

| گروه | پنجره‌های تحت پوشش |
| --- | --- |
| وب‌سایت و حساب | حساب شخصی، منوی موبایل، جست‌وجو، دستیار، بزرگ‌نمایی تصویر و برش عکس پروفایل |
| میزکار | ایجاد و ویرایش رکورد، جزئیات، تأیید عملیات، مدیریت رسانه، پیش‌نمایش صفحه و فرم، مقایسهٔ نسخه‌ها، جست‌وجو، راهنما و اعلان‌ها |
| CRM و محتوا | ادغام و ورود داده، عملیات تجاری، زمان‌بندی و انتشار و سایر مصرف‌کنندگان Modal مشترک میزکار |
| کروسل | پوستهٔ جزئیات و حالت نمایش گسترده، با حفظ منطق درگ و انتخاب کارت |

پنجره‌های بومی `dialog` همچنان مدیریت لایهٔ بالایی، فوکوس، بستن و قفل اسکرول را انجام می‌دهند. تنظیمات کاهش حرکت و خاموش‌کردن جلوه‌ها رعایت می‌شوند. سایدبارهای موبایل جهت و جایگاه کناری خود را حفظ می‌کنند.

## حفظ زبان انتخاب‌شده

زبان درج‌شده در مسیر جاری، مرجع زبان رابط است. اطلاعات ذخیره‌شدهٔ حساب، ورود، خروج، تعویض نقش یا ذخیرهٔ تنظیماتی مانند تم، نباید بدون انتخاب کاربر زبان صفحه را تغییر دهند.

- تغییر زبان از انتخابگر زبان یا ذخیرهٔ صریح زبان جدید انجام می‌شود.
- پیوندهای داخلی به زبان جاری ساخته می‌شوند؛ پیشوند زبان ذخیره‌شده در یک پیوند قدیمی، زبان رابط را ناخواسته عوض نمی‌کند.
- پارامترهای نشانی و لنگر صفحه هنگام تغییر زبان حفظ می‌شوند.
- پیوندهای خارجی، فایل‌ها و انتخاب صریح زبان یک مطلب، رفتار مشخص خودشان را دارند.
- نبود ترجمهٔ منتشرشدهٔ یک محصول، مجوز تغییر خودکار زبان کل رابط نیست؛ زبان موجود باید با انتخاب کاربر باز شود.

## ساخت و بررسی

پیش‌نیاز پروژه Node.js 24 یا جدیدتر است. دستورهای اصلی در ریشهٔ پروژه:

```bash
npm ci
npm test
npm run build
npm run check
```

برای اجرای خروجی ساخته‌شده، تنظیمات سروری را مطابق `.env.example` در `.env.local` قرار دهید و از `npm start` استفاده کنید. راهنمای پورت، سرور همراه پروژه و تنظیمات AI در README موجود است.

آزمون‌های مسیر و زبان، انتخاب صریح زبان، حفظ query/hash و جداسازی پیوند داخلی از فایل و نشانی خارجی را پوشش می‌دهند. آزمون‌های تعامل و نقش‌های موجود نیز اجرا می‌شوند. بررسی خروجی، مسیرها و فایل‌های محلی سایت و هماهنگی ZIP دانلود با سورس را کنترل می‌کند.

**مرز بررسی:** این محیط مرورگر تعاملی پشتیبانی‌شده یا گوشی واقعی در اختیار ندارد. بررسی کد، CSS، آزمون‌ها و ساخت، جای تأیید دیداری روی دستگاه واقعی را نمی‌گیرد. برای این مرحله، پنجره‌های جدول بالا را در هر دو تم، فارسی/عربی و یک زبان چپ‌به‌راست، عرض باریک و دسکتاپ، متن بلند، صفحه‌کلید موبایل و تنظیم کاهش حرکت بررسی کنید. سپس ورود، تعویض نقش، ذخیرهٔ تم و پیمایش از لینک محتوای منتشرشده را با زبانی متفاوت از ترجیح ذخیره‌شدهٔ حساب آزمایش کنید.

نسخهٔ کامل سورس هنگام ساخت بازسازی می‌شود و `SOURCE-MANIFEST.json` داخل ZIP، هش فایل‌ها را ثبت می‌کند. اعتبارنامه‌ها، وابستگی‌های نصب‌شده و خروجی ساخت جزو ZIP سورس نیستند.
