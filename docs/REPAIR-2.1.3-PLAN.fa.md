# برنامهٔ اجرایی و معیار تحویل ۲٫۱٫۳

هدف این نوبت، ادامهٔ اصلاح نسخهٔ واقعی سایت با حفظ طراحی است. فایل ارسالی ۲.۰.۰ از نظر checksum و manifest بررسی شد و همان نسخهٔ قدیمی پروژه است؛ مبنای اصلاح، بستهٔ ذخیره‌شدهٔ جدیدتر ۲.۱.۲ با SHA-256 زیر است:

```text
e747581e3ee1332215fcada1d797f05046b97715ab7c5b18906d59e5db89a73a
```

## ترتیب اجرا

1. تطبیق فایل ارسالی، حفظ دارایی‌ها و migrationهای قبلی و بازیابی آخرین سورس اصلاح‌شده.
2. بررسی مسیرهای حساس حساب، ثبت‌نام عمومی، نقش‌ها، نشست، آپلود و بازیابی؛ ایجاد regression برای اشکال قابل بازتولید.
3. اصلاح انقضای نشست و توکن پس از انتظار قفل دیتابیس، با آزمون واقعی PostgreSQL قبل و بعد از اصلاح.
4. اجرای آزمون‌های واحد، PostgreSQL، API، بررسی TypeScript و ساخت واقعی production روی سورس ثابت.
5. راه‌اندازی برنامه، worker و reverse proxy با دیتابیس مستقل؛ بررسی سلامت و گردش کار مرورگر، زبان‌ها و دسترسی‌ها.
6. بررسی URLها و metadata و اجرای Lighthouse برای تمام مسیرهای واقعی در موبایل و ۷۳ حالت منتخب دسکتاپ؛ دامنهٔ نهایی ۱۲۲۳ حالت است. دستگاه، شناسهٔ build، مسیر، امتیاز و حدود پوشش ثبت می‌شوند؛ صفحات خصوصی همچنان noindex می‌مانند. اصلاح محدود پیش‌نمایش گالری، مقایسهٔ نحوهٔ ارسال CSS و رفع پرشِ مشاهده‌شدهٔ بارگذاری منابع با حفظ طراحی، پیش از تثبیت سورس C3 بررسی شده‌اند. نتیجهٔ نسخه‌های قبلی به امتیازهای C3 اضافه نمی‌شود.
7. اجرای نصاب اصلی Ubuntu و سناریوی بکاپ/بازیابی با دادهٔ آزمایشی مستقل؛ ثبت خروج واقعی هر فرمان، تطبیق داده و لغو نشست‌های قدیمی.
8. به‌روزکردن راهنمای نصب، ارتقا، env، کاربران، AI، آپلود، بکاپ و SEO؛ ثبت حدود واقعی پشتیبانی و نتایج جاری، جدا از سوابق تاریخی.
9. ساخت ZIP از allowlist سورس، بررسی secretهای شناخته‌شده، بازکردن و تطبیق checksum تمام فایل‌های بسته و ارائهٔ ZIP، SHA-256، manifest و گزارش نهایی.

## معیار گزارش نتیجه

هر مرحله فقط با رسید اجرای همان مرحله موفق اعلام می‌شود. آزمون متمرکز زیرمجموعهٔ suite کامل است و دوباره به مجموع اضافه نمی‌شود. نتیجهٔ تاریخی روی نسخهٔ قبلی، نتیجهٔ اجرای تازهٔ ۲.۱.۳ محسوب نمی‌شود. خطای محیط آزمایش از خطای برنامه جدا ثبت می‌شود؛ خروج ناموفق به موفقیت تبدیل نمی‌شود.

نتیجهٔ نهایی و محدودیت‌های باقی‌مانده در [گزارش پذیرش](VERIFICATION.fa.md) و [وضعیت جاری](CURRENT-VALIDATION.fa.md) هستند. این برنامه، به‌تنهایی رسید موفقیت مراحل نیست.
